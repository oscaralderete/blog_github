# Adding a blog to an existing Laravel project

This is an elemental project to demonstrate how easy is to add a blog powered by WordPress in a Laravel project.

You just need 2 new routes with their controllers plus an ApiService.php also you need your WP API credentials you need to place in your .env file.

If you're a skilled Laravel dev in less than 15 minutes you can get a functional blog, but take it easy because I strongly recommend you adding custom meta tags to your template because of SEO.

You have take care WP provides some data as HTML and that could be risky; there are many ways to mitigate them, there's where your experience will help you, an easy way could be to set a strong Content Security Policy. If you're a newbie ask AI for ways to patch these risks.

# Cómo agregar un blog a un sitio web hecho con Laravel

Este repo ejemplifica como de forma muy sencilla se puede agregar un blog a un sitio web Laravel usando WordPress.

En breve sólo necesitas agregar 2 rutas con sus controladores y un archivo ApiService.php obviamente también necesitas registrar en tu archivo .env las credenciales de tu WP API.

Si eres un programador que domina Laravel en menos de 15 minutos puedes tener un blog funcional, aunque deberías tomártelo con calma pues es recomendable agregar tags meta a tus templates esto es por razones de SEO.

Ten en cuenta que la API de WP devuelve mucha data como HTML lo cuál podría tener algunos riesgos; obviamente hay formas de resolver eso, si tienes experiencia definir un sólido Content Security Policy lo puede arreglar todo. Si eres un novato te sugiero consultes la AI.
